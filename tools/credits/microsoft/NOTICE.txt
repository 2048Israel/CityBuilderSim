Microsoft's runtime libraries in Civic Ledger

The game carries these files of Microsoft's, unmodified and signed by Microsoft:

- the Microsoft Visual C++ 2015 - 2022 runtime: msvcp140.dll, msvcp140_1.dll, msvcp140_2.dll, vcruntime140.dll and vcruntime140_1.dll;
- the Universal C Runtime of Windows: ucrtbase.dll and the api-ms-win-*.dll files.

They come with the game's Java runtime, in runtime\bin, and with OpenJFX's graphics library, inside the game's jar in app\, which unpacks them into the .openjfx folder in your user folder when the game starts.
